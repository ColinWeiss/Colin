# Cache —— 新建 UI 的暂存区

UI 编辑器导出代码时，**已经存在的类**会把 `X.UI.cs` 写在 `X.cs` 旁边（按命名空间/文件位置找）；
**还没有类的新 UI** 一律先落在这里：

```
Colin/Modulars/UserInterfaces/Cache/<类名>.UI.cs
```

这是**暂存区，不是归宿**。导出后请自己在 Visual Studio 里把文件拖到你想要的命名空间文件夹
（VS 会顺带把 `.projitems` 里的 `<Compile Include>` 一起改掉），然后再把类补成
`partial class <类名>`、**在每个构造函数里调一次 `BuildBody()`**（声明 `partial void BuildBody();`）、
需要的话实现 `partial void OnBuildComplete()`。

文件头永远带着 `<auto-generated>`，所以**不要手改这个目录里的东西**后再拖走以外的编辑动作 ——
下次导出会整个覆盖。
